# Analyse des épidémies d'Ebola en RDC (1976-2025)
[Consulter le dashboard Power BI](https://app.powerbi.com/links/S-ybJ3j3G-?ctid=53bc24c5-73ad-421a-9408-3ea555be4a07&pbi_source=linkShare)


## Présentation du projet
ce projet consiste en l'analyse de 16 épidémies d'Ebola survenues en RDC entre 1976-2025 à l'aide de Power BI 

## Objectifs
- Etudier l'évolution des épidémies au fil du temps.
- Comparer les taux de l'étalité des différentes flambées.
- Identifier les provinces les plus touchées.
- Mettre en évidence les principaux indicateurs épidémiologiques.

## Outils utilisés 
- Power Bi
- Excel
- Data visualisation
- Analyse de données

## Principales analyses 
- Répartition géographique des épidémies.
- Evolution du nombre de cas et de décès.
- Comparaison des taux de létalité.
- Identification des flambées les plus importantes.
